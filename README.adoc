= nando

nando is a content-addressed repository for durable files. It commits content locally and can deliver it asynchronously to one selected GCS or S3-compatible backend.

For installation, setup, CLI, FUSE, WebDAV, and operations, see the link:https://kamichidu.github.io/go-nando/[nando manual].

The design authority is `docs/design.ir.yaml`; the implementation defines actual behavior. The manual projects user-facing information that can be verified against both.

For development, build, test, and package checks, see the tasks in `Taskfile.yml`.
