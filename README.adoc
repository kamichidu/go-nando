= nando

`docs/design.ir.yaml` is the sole semantic authority and direct design reference for this repository. See `docs/design-ir-migration.md` for the one-time source coverage record.

== Validate the design

Check out the official Design IR validator and provide its path:

[source,bash]
----
git clone https://github.com/kamichidu/design-ir.git ../design-ir
git -C ../design-ir checkout 455ed318b7bc409d3e1da320620ef92d457042b9
DESIGN_IR_REPO=../design-ir tools/validate-design-ir.sh
----

The script verifies the pinned schema digest, then validates structure and semantics with the official v1alpha1 validator. Unresolved representation gaps are reported as warnings; validation errors fail the command.
