# S3 / Wasabi

AWS S3 と S3-compatible storage は一つの S3 adapter を使います。AWS SDK v2 Default Credential Chain から認証します。TOML に access key や secret key を書きません。

1. 実行する daemon account に AWS credential chain で利用可能な identity を設定します。
2. Wasabi など AWS 以外の endpoint では endpoint と region を daemon TOML に設定します。AWS S3 では必要に応じ region を指定し、endpoint は省略します。

   ```toml
   [remote.s3]
   endpoint = "https://s3.us-west-1.wasabisys.com"
   region = "us-west-1"

   [remote]
   sync_idle_interval = "30s"
   sync_periodic_interval = "5m"
   max_delivery_delay = "30m"
   sync_parallelism = 2
   ```

3. S3-compatible repository を初期化します。

   ```sh
   nando --repository "$HOME/nando-data" init \
     --delivery-mode remote \
     --remote-backend s3 \
     --remote-uri s3://my-bucket/nando/
   ```

endpoint と region は runtime TOML、backend と URI は repository 設定が所有します。URI prefix は object key に文字どおり連結します。たとえば `s3://bucket/nando` は `nandoobjects/{content_id}`、`s3://bucket/nando/` は `nando/objects/{content_id}` になります。
